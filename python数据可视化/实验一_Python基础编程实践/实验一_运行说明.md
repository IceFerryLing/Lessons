## 打开和运行

1. 在 VS Code 中打开本文件夹，右上角选择内核 **Python (pppp 实验)**（等价于共享 `.venv/Scripts/python.exe`）。
2. 打开 `exp1.ipynb` 或 `实验一_完整解答.ipynb`，执行“Kernel → Restart Kernel and Run All Cells”。
3. 数据、结果均在本文件夹内读写，不依赖上层目录；参考解答输出写入 `output_lab1`。

也可以在命令行启动 JupyterLab：

```powershell
..\.venv\Scripts\python.exe -m jupyterlab
```

成绩输入默认使用 85 分，确保全部单元格自动运行；将 `interactive = False` 改为 `True` 可手动输入。

## 环境

使用上一级目录（`python数据可视化`）的共享 `.venv`（Python 3.11，含 JupyterLab、Matplotlib、nbconvert），不需要额外安装 Anaconda。VS Code 的默认解释器已指向这个虚拟环境。

若以后重建环境，先安装 Python 3.11，在 `python数据可视化` 根目录执行：

```powershell
python -m venv .venv
.venv\Scripts\python.exe -m pip install jupyterlab pandas numpy matplotlib seaborn pyecharts openpyxl
.venv\Scripts\python.exe -m ipykernel install --user --name pppp-lab --display-name "Python (pppp 实验)"
```
